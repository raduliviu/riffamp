# webamp starter pack — licensing & provenance

Every file in this folder is one webamp is legally permitted to redistribute
(bundle in the installer, host on the site). This is the pack that ships — the
repo's top-level `assets/` folder is local-dev-only and must never enter an
installer or hosted deploy.

## Amp model

**`Obsidian (Omega Ampworks).nam`**
- Capture of an Omega Ampworks *Obsidian* (hi-gain), modeled by **Steven Atkinson**.
- Source: the Neural Amp Modeler plugin repository
  (github.com/sdatkinson/NeuralAmpModelerPlugin), where it ships as the bundled
  sample model (`REAPER/model.nam`).
- License: **MIT** (repository LICENSE, © 2023 Steven Atkinson) — redistribution
  permitted with the license/copyright notice (see `MIT-NAM.txt`).
- Attribution kept deliberately: the display name credits the make/model, and
  the `.nam` metadata credits the capture author. This is a capture *credit*,
  not a claim of affiliation with Omega Ampworks.
