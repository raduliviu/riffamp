Browser UI, native engine

The browser is a great place for an interface and a terrible place for real-time audio. So RiffAmp splits the two: the controls live on a web page; a small native helper owns the audio path and talks to it over a local connection.

01

Install the helper

A ~2 MB native app. It runs quietly in your tray and owns the low-latency audio path to your interface.

02

Open the UI

The helper serves its own page locally — knobs, pedalboard, tuner, and practice tools, all in your browser.

03

Play

Guitar in, amp out, at the latency a native driver gives you — not what a browser sandbox allows.

Everything for a practice rig

Neural amp + cab

Load NAM captures and cabinet impulse responses. Bring your own or grab thousands from the community.

Pedalboard

Compressor, drive, chorus, delay, reverb — placeable before or after the amp, reorderable.

Tuner

Fast, accurate pitch detection on your clean input — works even while the amp path is muted.

Metronome

Sample-accurate click on the same low-latency path, with tap tempo and accents.

Drum machine

A step-sequencer groove box that shares the metronome tempo. Save and switch grooves.

Picking trainer

Real-time onset analysis tells you if you're actually playing 16ths — or slipping into triplets — at speed.

Download

Windows and macOS builds are ready. You'll need an audio interface with your guitar plugged in (ideally with an ASIO driver on Windows). The macOS build is for Apple Silicon.

RiffAmp isn't code-signed yet. On Windows you may see "unknown publisher" — click More info → Run anyway. On macOS, if it's blocked, open System Settings → Privacy & Security → Open Anyway. Both install for your user only — no admin needed.
